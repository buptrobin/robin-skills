01课本怎么说

先记住标准表述，再看解释。顺序反了，答题时就写不出术语。

课本原话人教版必修1 · 第5章第1节

酶是活细胞产生的具有催化作用的有机物，其中绝大多数酶是蛋白质。

→ 这句话里有 三个条件同时成立才算酶：① 活细胞产生、② 有催化作用、③ 是有机物。 少一个都不行——所以"从细胞里提取出来的酶在试管里照样能催化"，仍然满足"活细胞产生"这一条。

注意"绝大多数"三个字：少数酶是 RNA（核酶）。这个"少数"是选择题的常客， 写"酶的化学本质都是蛋白质"就直接判错。

04一道题走一遍

先自己读题干，想 30 秒，再点"下一步"。每一步都标了用到哪个概念。

例题必考

某同学用唾液淀粉酶探究温度对酶活性的影响，测得：20℃ 时活性约为最适值的 60%， 37℃ 时最高，50℃ 时几乎检测不到活性。
请回答：
（1）该实验的自变量和因变量分别是什么？
（2）把 20℃ 的酶液先升温到 37℃ 再降回 20℃，活性最终是多少？
（3）把 50℃ 的酶液降温到 37℃，活性能否恢复到最高？说明理由。

  1. 第 1 步 · 找变量

    自变量是温度；因变量是酶活性，用「单位时间内产物的生成量」或 「单位时间内底物的消耗量」来测。其余 pH、底物浓度、酶浓度都属于无关变量，必须相同且适宜。

    用到：单一变量原则 / 因变量的可测指标

  2. 第 2 步 · 判断"可不可逆"

    先给每一段定性：20℃ 属于低温，酶的空间结构没有被破坏，只是分子运动慢，可逆； 50℃ 属于高温，蛋白质空间结构已被破坏，不可逆。这一步定完，后面两问就有答案了。

    用到：低温抑制 / 高温变性失活

  3. 第 3 步 · 套用第（2）问

    20℃ → 37℃，活性升到最适（100%）；37℃ → 20℃，因为低温段可逆， 活性原路返回 60%。整个过程只发生了"慢—快—慢"，酶没有损失。

    用到：低温可逆 ⇒ 沿曲线往返

  4. 第 4 步 · 套用第（3）问

    50℃ 时酶已经变性，空间结构被破坏且不可恢复。所以即使把温度降到 37℃（最适温度）， 活性也不能恢复——酶已经不是原来那个酶了。注意区别：这不是"温度不合适"，是"酶已经坏了"。

    用到：高温不可逆 ⇒ 不能沿曲线返回

1 / 4

标准答案（可抄进答题卡）

（1）自变量：温度；因变量：酶活性（可用单位时间内淀粉的消耗量或还原糖的生成量表示）。
（2）最终为最适值的 60%。低温只抑制酶活性，未破坏其空间结构，恢复原温度后活性可恢复。
（3）不能。高温使酶的空间结构遭到破坏，这种变性不可逆；降温只能使温度回到最适值， 不能让已变性的酶恢复活性。

05会怎么考

选的都是"觉得自己懂了、一做就错"的角度。反直觉和易错两类要重点看。

「酶和无机催化剂都能降低活化能，区别到底在哪？」

三处不同：降低幅度（酶更显著，所以"高效性"）、专一性（一种酶只催化一种或一类反应）、 条件（酶要温和的温度和 pH，无机催化剂耐得住）。判据是这三条，不是"酶更厉害"。

「加了酶，反应放出的热量会变多吗？」

不会。酶不提供能量，也不改变反应物和产物的能量。放出的热量由始态和终态的差决定， 这个差没变，所以热量一样多；变的只是"多快放完"。

「酶在反应前后会被消耗掉吗？」

不会被消耗。酶在反应前后化学性质和数量都不变，可以反复使用。 所以极少量的酶能催化大量的底物——这也是"催化剂"三个字自带的含义。

「温度越高，酶活性越高吗？」

不是。酶有最适温度，超过之后活性下降。人体酶最适约 37℃，唾液淀粉酶也在此附近； 而耐热菌的酶最适可以到 70℃ 以上——"最适温度"不是一个固定数字。

「验证酶的高效性，为什么用无机催化剂作对照，而不是空白对照？」

因为"高效"是比较出来的，必须有"能催化但弱一点"的参照物。 空白对照（不加任何催化剂）只能证明酶"能催化"，证明不了"更高效"。 同理，验证专一性要用"同一种酶 + 另一种底物"作对照。

「低温保存酶制剂，是因为低温让酶更稳定吗？」

说法要改。低温是抑制活性、不破坏结构，相当于让酶"暂停工作"， 需要时升温即可恢复。所以说"低温使酶暂时不发挥作用"准确，说"低温使酶更稳定"就跑偏了—— 真正的稳定是结构没被破坏，而不是低温给了它什么好处。

这六问其实是同一件事：分清"活性低"和"酶坏了"。 低温 = 活性低但没坏（可逆）；高温 = 坏了（不可逆）；不加酶 = 根本没有这个人。 三条判据一分开，绝大多数酶的选择题都能直接选。

06易错清单

左边是考试里真的会写出来的错句，右边是应该写的样子。后者可以直接背。

✗ 低温使酶变性失活

✓ 低温只抑制酶的活性，空间结构未被破坏，回升温度后活性可以恢复

错在哪：把"活性低"当成了"酶死了"。只有高温、过酸过碱才会破坏空间结构。

✗ 酶能为反应提供能量

✓ 酶降低化学反应的活化能，不提供能量

错在哪：把"加快"和"供能"混为一谈。加快是因为门槛低了，不是因为给了能量。

✗ 酶只在细胞内起作用

✓ 酶由活细胞产生，但在细胞外、体外也能起作用

错在哪：把"产生场所"当成了"作用场所"。唾液淀粉酶在口腔里工作，加酶洗衣粉里的酶在洗衣机里工作。

✗ 酶的化学本质都是蛋白质

✓ 绝大多数酶是蛋白质，少数是 RNA

错在哪：漏掉课本里"绝大多数"三个字。凡出现"都是""一定"的表述，先怀疑。

✗ 加酶能提高产物的最终生成量

✓ 酶只加快反应速率，缩短到达平衡的时间，不改变平衡点

错在哪：产物量由反应物总量和平衡常数决定，酶不参与这个账。

✗ 高温和低温都会使酶失活

✓ 高温使酶变性失活（不可逆）；低温只抑制活性（可逆），两者机制不同

错在哪：把"活性下降"这同一个现象，错当成同一种原因。这也是图 3 那条曲线不对称的理由。
