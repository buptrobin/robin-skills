# eli5-high · 高中版图解讲义

把高中课本里"看不懂的那一页"，做成一页**能看懂、能复习、能答题**的 HTML 讲义。

Topic: $ARGUMENTS

## 与 eli5 的分工（先看这张表，别混）

| | `eli5` | `eli5-high` |
|---|---|---|
| 读者 | 零基础，只想建立直觉 | 学过一遍、要考试，卡在某个概念上 |
| 目标 | "原来是这样" | "这样我就不会被扣分了" |
| 术语 | 可以完全不用术语 | **必须用课本原话**，比喻只能当附注 |
| 文字量 | 图多字少，一句一图 | 每图配 2–3 行精确说明，密度更高 |
| 必备区块 | 别人会怎么问你 / 它从哪来 | 课本原话 / 拆开看 / 互动 / **一道题走一遍** / **易错清单** |
| 检验标准 | 读者能复述直觉 | 读者能把课后题做对 |

⚠️ 两者**共用同一套工程规范**（B 级互动的判断与实现、单文件零依赖、手机优先、验证链），
这部分直接看 `references/interactive.md`，不要重新发明。

## 第一步：动手前先写下"三件套"

写不出来就别开始画。这三行是整个页面的地基。

1. **课本定义原话** —— 哪本书、哪一章、教材是怎么说的（照抄，不许改写）。
2. **这一节最容易丢分的 3 个点** —— 不是"难点"，是**扣分点**：学生觉得懂了、一考就错的地方。
3. **判断记录** —— 拖「____」→ 看到「____」变 → 因此相信「____」。（见第二步）

## 第二步：适配性判断（标准比 eli5 略宽）

高中内容多数天然适合做 B 级，因为教材本身就是"一个量变化 → 曲线/图形跟着变"。

**✅ 适合做 B 级**（命中任意 2 条）

- 有连续可调的量：温度、pH、浓度、角度、利率、种群数量、电压、pH、投料比、时间
- 图形随它改变形态：曲线弯法、能垒高度、面积、位置、颜色深浅
- 存在**反直觉**结论（低温为什么不杀死酶、为什么加酶不改变平衡点）
- 有**临界/极端**情形值得看：最适值、饱和点、恰好失效、恰好中和
- 多层依赖：A 变 → B 变 → C 变（静态图说不清这条链）

**❌ 退回 A 级 / 静态**（命中任意 1 条）

- 纯分类清单（元素分级、细胞器名单）→ hover / 点击展开
- 时间线、流程叙事（光合作用发现史）→ 步骤机或静态
- 并列离散选项（三种细胞分裂方式的对比）→ 静态对照表
- 数据是外部真值不随参数变（某地的气候数据）→ 静态
- 参数不连续（只有几个合法取值）→ 换按钮，别用滑块骗人
- 一页已经有互动点了 → 保持静态

**档位**：是什么 → A；怎么变 → B；怎么走 → B+ 步骤机；多个量互相影响 → C 多图联动。
**一页最多 1–2 个动手点**，其余静态。典型结构 = 静态讲解打底 + 1 个互动收尾。

**B 级一律带 Autopilot 自走**：空闲时图形自己在演，读者一碰就接管，松手 5 秒交还。
「读者不知道这张图能拖」是本技能最容易翻车的地方，规范见 `references/autopilot.md`，引擎在 `assets/autopilot.js`。

判断为静态时**必须指出命中了哪一条**，并在交付说明里讲清理由。不允许因为"做静态更快"悄悄退回。

## 第三步：页面必备六区块（缺一不可）

### A. 课本怎么说

引用卡片，照抄教材定义 + 一句话翻译成人话。**先给标准表述，再给解释**，顺序不能反。
写明出处（人教A版必修一 P82 之类），读者要能翻回去对照。

### B. 拆开看（2–5 张图）

每张图配 **2–3 行精确说明**，不是一句话。说明里要出现课本术语。
一图只讲一件事；同一张图里不要塞第二层信息。

### C. 自己拖一下

B 级互动面板：拖参数 → 图形与数值实时重算。选哪个参数由第二步的判断记录决定。
必须同时给出**三个可读数值**（当前参数、被影响的量、状态判断），否则读者不知道自己看到了什么。

**这一块默认接 Autopilot**（`assets/autopilot.js`，产出时必须全文内联）：

- 空闲时图形自己在演，**滑块的圆点跟着动**——这是唯一有效的「可拖」提示，**不要写「请拖动滑块」**
- 循环 10–15 秒，**中间必须有一格停 2–3 秒**（全篇最值钱的那一帧）；写不出这一格，说明这个主题不该自走
- 读者拖动 / 点画面 / 按方向键即接管，**松手 5 秒自动交还**，交还时从最接近的相位接回、不跳帧
- 点画面依次跳到 3–5 个关键值（按叙事顺序，不是均匀采样），门槛远低于拖 17px 的圆点
- 顶部必须有**状态徽标**（自动演示中 / 你接管了），否则读者分不清「在动」和「坏了」

完整 API、循环设计与八个坑见 `references/autopilot.md`。

### D. 一道题走一遍

**这是 eli5-high 与 eli5 最大的区别。** 挑一道最典型的题（课后题 / 高考真题的原型），
**分步揭示**：先只给题干，读者自己想，点"下一步"才展开该步的推理，最后落到"标准答案长什么样"。

规矩：
- 每步只推进一个判断，不要一步跨三跳
- 每步末尾标出"这一步用到的是哪个概念"
- 最后必须给出**可抄进答题卡的表述**（分点、术语到位）

### E. 考你会怎么考（5–8 问）

替读者预演被追问的姿势。六类角度里**这四类最值钱**：

| 角度 | 典型问法 |
|---|---|
| 定义辨析 | 「A 和 B 到底差在哪」 |
| **反直觉** | 「为什么加了酶反而…… / 为什么低温不杀死它」 |
| **易错点** | 「能不能写成……」 |
| 边界/极端 | 「能到 0 吗 / 能超过 100% 吗」 |

每问配一句话答案 + 一张 240×132 迷你图。收尾点明「这几问其实是同一件事」。

### F. 易错清单（5–8 条）

两栏对照：左边 ✗ 错误表述（学生真实会写的），右边 ✓ 正确表述（课本语言）。
每条再跟一句"为什么会错"。**这一节决定这页是"好看"还是"有用"。**

## 第四步：版式与视觉（讲义版，不要照抄 eli5 的留白）

- **kicker 固定写「ELI5-HIGH · 讲给要考试的人」**
- 沿用 eli5 的**语义色**（蓝=主/正向，绿=正确/安全，琥珀=警示/重点，红=错误/危险），不要自创一套
- 但版式更密：正文 `line-height:1.72`，段落间距小；宽屏可用两栏承载"辨析表 / 易错清单"
- 引入**考点徽章**（四色，见 `references/handout.md` §2），标在标题旁：`必考` `易错` `辨析` `延伸`
- 顶部给一条**章节目录**（就是各区块标题的锚点），高中生要能跳着看
- 每个重要结论后面挂一个 `数据来源` 小注（教材页 / 实验值），**数字必须能追**，不许编

## 第五步：内容质量四条硬线

1. **术语照课本**：该叫"活化能"就不许叫"门槛"；该叫"基因的分离定律"就不许叫"一半一半定律"。比喻写在定义之后，作为`.aside`附注。
2. **每个概念必须落成"能看见的量"**：图、表、或可拖的参数。连续文字段落不超过 3 行。
3. **数字要能追来源**：教材值、实验值、或明确标注"示意值"。同一个数字在全文必须一致（别一页里出现两个不同的水含量）。
4. **禁用语**：「简单来说」「众所周知」「其实很简单」「只要记住」。这些词出现的地方，通常就是你没讲清的地方。

## 第六步：动手前记住七个坑

前五个与 eli5 相同（见 `references/interactive.md` §6），另外两个是讲义版特有的：

1. SVG 圆弧方向：y 轴朝下 ⇒ 数学逆时针 = `sweep-flag 0`
2. `pointerdown` 挂 SVG 根节点，不挂手柄图形
3. `hidden` 会被类里的 `display` 顶掉 → 补 `.cls[hidden]{display:none}`
4. 浮动文字加白色光晕 `.halo`
5. 反向拖拽让角度变负 → 圈数用 `Math.abs`
6. **教材数值不许"凑"**：如果要让模型跑出课本那张表，就得把模型参数**反解出来**并在页脚声明口径，
   而不是硬编码一个"看起来像"的数字。读者拿课本一对就对出来了。
7. **同一页里的两套口径必须显式说明**：教材不同章节使用的分母/条件常常不一致
   （例：成分表按"细胞"算、元素表按"人体整体"算）。发现矛盾不要绕开，写成一个"易错点问答题"——那正是最值钱的内容。

## 第七步：验证链（与 eli5 相同，不许跳过）

```bash

node scripts/drive.mjs <page.html> --actions <steps.json> --width 1440 --height 1100
```

规矩：
- 页面长时先 `["scroll", sel]`，否则拖拽/点击静默失败

- 最后一行必须 `console: clean`
- 每张图单独截图看：`node scripts/capture.mjs <page> --select "figure:nth-of-type(N)"`
- 多宽度回归 360 / 390 / 768 / 1024 / 1440，横向溢出必须为 0
- **首屏必须单独截一张**（逐图截图看不到页面顶部）

另外在 `prefers-reduced-motion` 下初次进入必须直接是 `"manual"`。见 `references/autopilot.md` §6。

## 第八步：交付时说什么

不要只说"做好了"。用四句话交代：

1. **判断结论**：这页做成了哪一档，为什么（引用判断记录那一句）
2. **模型口径**：用了什么数据、怎么校准的、误差在哪
3. **验证结果**：跑了哪些断言、哪些宽度、console 是否干净
4. **它对应教材哪里**：哪本书哪一章，可以对着翻

超过四句就是啰嗦了。
