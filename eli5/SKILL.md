## 本机约定：先判断适配性，合适就做成能动手玩的

### 第一步：判断（动手画之前必须做完）

问自己：**这个主题里有没有「改一个量，图形就会跟着变」？**
有 → 做 B 级参数联动。没有 → 别硬做，退回 A 级或静态。

**✅ 适合做 B 级**（命中任意 2 条就做）

- 有一个**连续可调的量**：角度、时间、频率、半径、比例、阈值、权重、浓度、速度……
- 图形会**随它改变形态**：曲线弯法、线段长短、面积大小、位置、颜色深浅
- 存在**反直觉、要自己试才信**的结论（「转过去为什么冒出负号」「周期为什么减半」）
- 有**多层依赖**：A 变 → B 变 → C 跟着变，静态图说不清这个链
- 有**值得看的临界或极端情形**：趋近 0 / 无穷、断点、相变、刚好失效的那一刻
- 读者的真实疑问是「**如果我改成 X 会怎样**」

**❌ 不适合**（命中任意 1 条就退回 A 级或静态，别硬做）

- 主题是**清单 / 分类 / 术语对照** —— 没有「量」，拖什么？硬做就成了玩具
- 主题是**时间线 / 历史 / 流程叙事** —— 顺序是固定的，做成拖拽很怪
- 只是**并列对比几个离散选项**（三种方案、四个型号）—— 读者要同时看全，不是拖（→ 静态对照表 + hover 高亮）
- 数据是**外部给定的真值**，不随任何参数变（→ 静态）
- 参数**本身不连续**（只有几个合法取值）—— 滑块会撒谎（→ 改成按钮切换）
- 一页里**已经有互动点**了，再塞会让人疲于操作

**判断记录**（写不出这句话就说明不合适）：
> 读者拖「____」→ 看到「____」变 → 因此相信「____」。

**允许混搭，而且通常这样最好**：静态讲解打底 + 1 个互动收尾。
一页最多 1–2 个动手点，其余保持静态——读者的注意力是有限资源。
（参考：`examples/trig-page-full.html` 就是 6 张静态讲解图 + 1 个互动面板的结构。）

### 第二步：兜底与反偷懒

判断为「不合适」时，**必须能指出上面哪一条命中**，并在交付说明里讲清为什么这一页没有动手点。
**不允许**因为「做静态更快」就悄悄退回静态——那不是判断，是偷懒。
反过来，主题合适却做成静态，等于把最关键的那个「变」字丢掉了。

### 各档位怎么选

| 主题形态 | 档次 | 做法 |
|---|---|---|
| 一个东西**是什么**（术语、分类、清单） | A | hover 高亮 / 点击展开 / 切换视图 |
| 一个关系**怎么变**（函数、机制、权衡） | **B** | 拖参数 → 图形与数值实时重算 |
| 一套流程**怎么走**（步骤、规则、判断） | B+ | 可前进/后退的步骤机，或先让他猜再揭晓 |
| 多个量**互相影响** | C | 多图联动（拖一处几处一起动）+ 自动演示 |

### 内容必备的两个区块

**① 「别人会怎么问你」——每次都要有**

听懂 ≠ 扛得住追问。这一节替读者**预演他会被怎么问**：列 4–8 个最可能被考/被问的角度，
每个配一句简明答案 + 一张迷你图。六类角度里，**反直觉**和**易错点**最值钱——那正是读者自己也没想通的地方。
收尾必须点明「这几问其实是同一件事」，否则读者拿到的是一堆孤立知识。

**② 「它从哪来」——有料才写，宁缺毋滥**

只写**有人、有年份、有动机**的真实节点，优先挖「意外的转折」而不是流水账。
⚠️ **没有真进展就明确不写「最新发现」**——数学/理论类主题多数没有时效性新闻，定理不会过期。
不许用「近年来研究者不断探索」充版面。退一步的诚实写法是写「它今天长到哪去了」，把当代应用作为时间轴最后一站。

细节与模板见 `references/interactive.md` 第 9、10 节。

### 第三步：硬性约束

- **单文件、零外部依赖**：内联 CSS + 内联 JS + 手写 SVG。不引 CDN、不引图表库、不引字体。
- **几何一律运行时算**，不预生成 path 数据。五个 helper 就够：`pt()` / `arcD()` / `xOf()/yOf()` / `el()`。
- **三种输入都要能用**：鼠标拖、触摸拖（Pointer Events 一套代码）、键盘（`tabindex="0"` + 方向键，Shift 加速）。
- 中文界面，light 主题；数值面板实时更新到 3 位小数；退化情形要有兜底文案。
- 页首 kicker 固定写 **「ELI5 · 讲给想探知的人」**（讲给好奇的人，不是讲给无知的人）。
- **手机优先**：默认假设这页会被转发到手机上看。窄屏要能正常阅读——静态宽图给「点击放大」浮层，
  互动图把「并排」换成「上下堆叠」（读者得同时看见拖的东西和变的东西），任何宽度下都不能横向溢出。
  详见 `references/interactive.md` 第 8 节。

### 动手前先记住的五个坑

1. **SVG 圆弧方向反直觉**：y 轴朝下 ⇒ 数学逆时针 = `sweep-flag 0`；顺时针运动在 θ 处的箭头切线 = θ−90。
2. **`pointerdown` 挂 SVG 根节点**，不要挂手柄图形 —— 手柄中心会被后画的线/点盖住，事件落在兄弟节点上不冒泡，**静默失效**。
3. **`hidden` 会被类里的 `display` 顶掉** → 补 `.cls[hidden]{display:none}`。
4. **浮动文字要白色光晕**：`.halo{stroke:#fff;stroke-width:3.6;paint-order:stroke}`。
5. **反向拖拽会让角度变负** → 圈数显示一律用 `Math.floor(Math.abs(alpha)/360)`，否则出现「第 0 圈（已转 -1 整圈）」。

### 第四步：验证链（不许跳过）

静态截图证明不了 JS 有没有跑。做完必须用 anatomy skill 的 drive.mjs **真跑一遍**：
模拟拖拽 / 点击 / 按键 → `eval` 读回数值面板 → 跟几何真值对账 → 看 `console: clean`。

⚠️ **页面长时必须先 `["scroll", sel]`**，否则指针事件落在视口外，drag / click 会静默失败。

完整配方（适配性判断表、配色、骨架、交互四件套代码、actions JSON 样例、交付清单）见 `references/interactive.md`。
可直接抄的成品见 `examples/trig-page-full.html`（完整页，含响应式）；
手机端效果基准见 `examples/trig-phone-390.png` 与 `examples/trig-phone-board.png`。

### 隔壁有个 `eli5-high`

如果话题是**高中课程内容**（教材某章某节、要考试、要能答题），并且 `eli5-high` 可用，
**优先用 `eli5-high`**——它保留同一套工程规范，但加了课本定义原话、分步例题、易错清单，
版式也从"绘本"换成"讲义"。本 skill 更适合零基础科普、跨学科概念、非应试的"这是什么"。
